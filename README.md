# 星愿衣橱 · Starlight Atelier

原创二次元童话风 3D 公主换装与轻冒险游戏。换上心爱的裙装，去遇见新的故事。

**在线游玩：[leeweir.github.io/royal-closet](https://leeweir.github.io/royal-closet/)**

## 玩法

- **我的衣橱**：36 件服饰、6 个部位，初始拥有 12 件。真实 3D 换装、自由染色、旋转查看、姿势切换、拍照下载和 3 个搭配收藏位。
- **星愿冒险**：花语森林、蔷薇庭院、琉璃海岸、月影雪原、星穹王城，共 20 个顺序解锁的关卡。采集 5 颗星晶、结识精灵、解开符文并进入传送门结算奖励。服饰与地区风格相符时，每件额外获得 8 金币，每两件额外获得 1 织梦丝。
- **三种符文**：顺序记忆、相邻翻转点灯、接住移动星光。失误不扣除资源，点灯有提示，记忆可反复查看。
- **织梦工坊**：冒险获得金币与织梦丝，探索新章节解锁图纸。15 星晶可以兑换 8 织梦丝，无付费购买。
- **搭配舞会**：自然、甜美、优雅、梦幻四种主题，根据身上六件服饰评分。每个主题每天首次参与可获得奖励，之后可免费挑战高分。
- **持续成长**：重复探索奖励、首次通关奖励、七日循环签到、每日委托、收藏成就和等级。通关全部故事后可以继续自由探索；没有体力限制。

点击地面移动，也可以使用 **WASD / 方向键**或屏幕方向按钮。靠近精灵、符文台、传送门后点击互动按钮，或按 **E**。衣橱内拖动旋转、滚轮缩放。

## 存档

进度自动保存于当前浏览器的 `localStorage`，没有服务器和账户。设置内可导出 / 导入 JSON 存档，在设备间转移进度。导入前会校验数据并要求确认替换。未完成的探索不会结算，也不会跨刷新保存。

音效默认关闭，可在设置内开启。图片下载保存透明背景 3D 场景。运行冒险需要支持 WebGL 的现代浏览器和图形加速。

## 本地运行

```sh
npm ci
npm run dev
```

```sh
npm run check       # 游戏规则测试、TypeScript 检查、生产构建
npm run preview    # 预览构建产物
```

浏览器验收脚本（需本地服务运行于 4173，并已安装 Playwright Chromium）：

```sh
npx playwright install chromium
npm run dev -- --port 4173
node tests/browser.mjs
node --import tsx tests/extended.mjs
```

`TEST_URL` 可指定已部署的网站地址。脚本通过实际鼠标与方向按钮完成冒险、奖励领取、搭配和存档恢复，并验证 390×844、320×740、844×390 的布局。截图保存在忽略的 `test-results/` 目录。扩展验收使用通关存档夹具检查后期地区、制作、另外两类符文和存档导入导出。macOS 验收默认使用 Metal；其他平台可移除测试脚本中的 `--use-angle=metal` 参数。

## 技术与素材

TypeScript + Vite + Three.js。游戏规则在 `src/simulation/`，3D 表现在 `src/render/`，界面在 `src/main.ts` 和 `src/style.css`。原创建模由程序化几何生成，面部纹理由 Canvas 绘制；王国地图使用 OpenAI imagegen 原创生成；图标使用 Lucide。字体使用本地系统中文字体，不依赖外部字体服务。

GitHub Actions 在推送到 `main` 时先运行规则测试和构建，再发布到 GitHub Pages。全部游戏内容为静态文件。
