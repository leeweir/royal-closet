# 星愿衣橱 · Starlight Atelier

二次元童话风 3D 公主换装与轻冒险游戏。换上心爱的裙装，去遇见新的故事。

**在线游玩：[leeweir.github.io/royal-closet](https://leeweir.github.io/royal-closet/)**

## 玩法

- **我的衣橱**：36 件服饰、6 个部位，初始拥有 12 件。VRM 公主搭配六种独立剪裁的 3D 裙装、冠饰与羽翼、6 个完整套装的一键选择、自由染色、旋转查看、眨眼和视线跟随。点击「试穿模式」或未拥有的单品 / 未集齐套装，可以预览和混搭所有服饰、染色；试穿不会保存或解锁服饰，不能存入搭配收藏，退出、离开衣橱或刷新后恢复正式搭配。冒险能力和舞会评分使用正式搭配。笑脸按钮切换自然、开心、温柔、惊喜、俏皮五种表情；支持点击微笑、挥手和展示动作、拍照下载和 3 个搭配收藏位。
- **星愿冒险**：花语森林、蔷薇庭院、琉璃海岸、月影雪原、星穹王城，共 20 个顺序解锁的关卡。各地区有独立路线与地标，同章四关旋转整条路线，形成 20 个布局。分别结识花语精灵露露、茶会兔管家绵绵、人鱼歌者汐汐、月灯雪狐霜霜、王城星使奥莉，每位都有专属对话。采集 5 颗星晶、结识伙伴、解开符文并进入传送门结算奖励。服饰与地区风格相符时，每件额外获得 8 金币，每两件额外获得 1 织梦丝。
- **三种符文**：顺序记忆、相邻翻转点灯、接住移动星光。失误不扣除资源，点灯有提示，记忆可反复查看。
- **织梦工坊**：冒险获得金币与织梦丝，探索新章节解锁图纸。15 星晶可以兑换 8 织梦丝，无付费购买。
- **搭配舞会**：自然、甜美、优雅、梦幻四种主题，先进行约 9 秒的入场、转身、致意和退场走秀，再根据登台时的六件服饰评分；可跳过演出或返回准备，返回不结算。每个主题每天首次参与可获得奖励，之后可免费挑战高分。
- **持续成长**：重复探索奖励、首次通关奖励、七日循环签到、每日委托、收藏成就和等级。通关全部故事后可以继续自由探索；没有体力限制。

点击物品或地面移动，点击上方目标自动引路，也可以使用 **WASD / 方向键**或屏幕方向按钮。靠近伙伴、符文台、传送门后点击互动按钮，或按 **E**。衣橱内拖动旋转、滚轮缩放。冒险镜头跟随公主；步态按实际位移推进，有交替抬脚、屈膝、摆臂和停止过渡，暂停时清空移动目标。

服饰能力实际参与冒险：鞋履改变步速，羽翼扩大自动采晶半径，魔杖的「共鸣」可收集一定范围内的星晶并进入冷却。裙装风格与地区一致时，魔法半径增加 0.6 米、冷却缩短 2 秒。套装页和玩法指南均可查看当前能力。

界面保留暖紫与奶油白：衣橱使用悬挂吊牌，工坊用系列色块的设计图纸，舞会用金边邀请函，地图用章节纸页，手帐用连续的心愿记录。

所有主界面采用一屏布局；桌面、手机竖屏和短横屏均无需整页滚动。工坊和手帐用分页查看全部收藏与任务。

## 存档

进度自动保存于当前浏览器的 `localStorage`，没有服务器和账户。读档时会自动修复已下架的服饰或损坏的字段；无法修复的存档会先备份，可在设置中下载。多个标签页同时打开时会自动同步进度。设置内可导出 / 导入 JSON 存档，在设备间转移进度。导入前会校验数据并要求确认替换。未完成的探索不会结算，也不会跨刷新保存。

音效默认关闭，可在设置内开启。图片下载保存透明背景 3D 场景。运行冒险需要支持 WebGL 的现代浏览器和图形加速。

## 本地运行

```sh
npm ci
npm run dev
```

```sh
npm run check       # 游戏规则测试、TypeScript 检查、生产构建
npm run preview    # 预览构建产物
```

浏览器验收脚本（需本地服务运行于 4173，并已安装 Playwright Chromium）：

```sh
npx playwright install chromium
npm run dev -- --port 4173
node tests/browser.mjs
node tests/fitting.mjs # 试穿单品、套装、染色与存档隔离、退出恢复、响应式截图
node --import tsx tests/extended.mjs
node tests/touch.mjs
node tests/adventure-controls.mjs # 按键松手、跟随镜头、多点触控、四种屏幕
node --import tsx tests/adventure-features.mjs # 六件套、走秀结算、五地区 NPC 与主动魔法
node tests/one-screen.mjs
node --import tsx tests/visual.mjs
node --import tsx tests/accessory-audit.mjs
node --import tsx tests/vrm-wardrobe.mjs
node tests/vrm-loading.mjs
node tests/vrm-fit.mjs # 发型和鞋履近景检查，需 Vite 开发服务
node tests/anime-wardrobe.mjs # 裙身贴合、六款魔杖握持与浏览器多角度截图

```

`TEST_URL` 可指定已部署的网站地址。脚本通过实际鼠标与方向按钮完成冒险、奖励领取、搭配和存档恢复，并验证 390×844、320×740、844×390 的布局。截图保存在忽略的 `test-results/` 目录。扩展验收使用通关存档夹具检查后期地区、制作、另外两类符文和存档导入导出。macOS 验收默认使用 Metal；其他平台可移除测试脚本中的 `--use-angle=metal` 参数。

## 技术与素材

TypeScript + Vite + Three.js + `@pixiv/three-vrm`。游戏规则在 `src/simulation/`，3D 表现在 `src/render/`，界面在 `src/main.ts`，响应式布局在 `src/style.css`，统一绘本主题在 `src/atelier.css`。公主使用 pixiv 官方示例 VRM 底模，运行时调整发色、服饰和材质，模型来源与授权见 [public/models/README.md](public/models/README.md)。自制服饰由程序化几何生成，全部衣橱使用 MToon 卡通材质，以色块、柔和阴影和几何裙边表现细节；皇冠与鞋履取消物理反光，羽翼只在薄膜和冰晶上保留适量透明，天使羽翼使用简化的层叠羽片；王国地图使用 OpenAI imagegen 原创生成；图标使用 Lucide。字体使用本地系统中文字体，不依赖外部字体服务。

### VRM 与服装适配

VRM 通常承载完整角色。VRoid 服装生态还包括 [.vroidcustomitem 与 XWear](https://vroid.pixiv.help/hc/en-us/articles/39513431300377-What-are-custom-items)；可以先在 VRoid 中适配和组合，再导出完整 VRM。three-vrm 本身不会自动把任意服装贴合到任意角色。

当前六套裙装按这位公主的体型调整，并绑定到同一套标准骨骼：袖子跟随上臂，皇冠与头发跟随头部，鞋子跟随脚，魔杖跟随手。服装可在挥手时切换，初始绑定姿态保持不变。长裙保留设计轮廓并采用较小步幅，短裙采用更清楚的抬脚动作；目前没有通用服装导入或布料碰撞模拟。VRM 文件约 10.3 MiB，首次加载显示等待状态，失败后可重试。`/princess-preview.html` 可单独查看正面与斜侧面。

裙身与身体共用躯干轮廓，领口使用贴身布边和肩带，月光裙增加花瓣叠层与星形腰结。六款魔杖使用统一掌心握点和弯肘握持姿势，杖头朝向角色正前方，晶石使用不透明卡通材质，避免透明排序丢失细节。预览支持 `?view=wand&wand=4`、`?view=hand&wand=0` 和 `?view=bodice&dress=1`；这些选择不影响游戏存档。完整套装预览可同时指定 `dress`、`hair`、`crown`、`shoes`、`wings`、`wand`，值为 0–5。

发型以 VRM 原有的头皮、刘海和发际线为基础。发束沿原有 UV 曲线重建平滑曲面，长发渐进绕过肩胸，短发在下颌处裁短收尖，避免把长发的弯折压缩到脸颊旁；默认长发保留原有弹簧骨骼权重，并在模型缩放和摆姿后重新初始化弹簧状态，避免动态发丝上翘。行走时在角色自身坐标中模拟发丝，避免平移或转身把长发甩成直线。双马尾和编发使用更密的曲线采样，并平滑接缝法线。`hair-surface.test.ts` 对实际 VRM 的发束转角、短发末端和骨骼权重做回归检查。鞋面依据该模型的脚掌轮廓重建，鞋口留出真实开口；长靴从脚踝到小腿使用混合骨骼权重。`vrm-fit` 会用真实头皮射线和脚掌顶点检查贴合，并保存六种发型、六双鞋的正面、侧面、背面与迈步近景。预览页也支持 `?view=head&hair=1` 和 `?view=feet&shoes=4&dress=1`，不影响游戏存档。

GitHub Actions 在推送到 `main` 时先运行规则测试和构建，再发布到 GitHub Pages。全部游戏内容为静态文件。
